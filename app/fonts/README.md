# Bundled fonts

PathippuAI draws published PDFs with the Noto Sans family so every supported script renders correctly:

| File prefix | Script | Used for |
|---|---|---|
| `NotoSansTamil` | Tamil | Tamil text |
| `NotoSansTelugu` | Telugu | Telugu text |
| `NotoSansKannada` | Kannada | Kannada text |
| `NotoSansMalayalam` | Malayalam | Malayalam text |
| `NotoSansDevanagari` | Devanagari | Hindi text |
| `NotoSans` | Latin | English text, digits and punctuation inside other scripts |

Regular and Bold of each were downloaded from the Noto build repository
(https://github.com/notofonts/notofonts.github.io, `fonts/<Family>/full/ttf/`).
